# Локальный линейный тренд (LLT)

*English version: [local-linear-trend.md](local-linear-trend.md).*

Класс: `Domain\Model\Finance\LocalLinearTrend`. Задача — очищенная от шума
цена и её текущая скорость для трендовых стратегий.

## Уравнения

```
x = [p, v]ᵀ                          n = 2
F = [1  dt]        Q = σ_a² · [dt³/3  dt²/2]
    [0   1]                    [dt²/2  dt   ]
z = [quote]                          m = 1
H = [1 0]          R = half_spread² + tick²/12
```

Это модель `p̈ = белый шум` (continuous white-noise acceleration). `Q` —
точная дискретизация; диагональная `Q = diag(q_p, q_v)` не соответствует ни
одному непрерывному процессу и даёт несогласованный фильтр — тест
консистентности это ловит.

## Параметры

| Параметр | Смысл | Как выбрать |
|---|---|---|
| `sigmaA` | интенсивность смены тренда | MLE по невязкам (`App\Calibration`), стартово — дневная σ доходности / √(дневных секунд) × 3 |
| `halfSpread` | половина спреда | из стакана |
| `tick` | шаг цены | дисперсия дискретности tick²/12 добавляется к R |

## Использование

```php
$llt = new LocalLinearTrend(sigmaA: 0.5, halfSpread: 0.05, tick: 0.01);
$filter = $llt->filter(firstPrice: 100.0);          // Sequential2 — развёрнутое ядро, ~0.6 мкс/шаг с JIT
$filter->step(Measurement::at($tsNs, [0 => $quote]));
$score = LocalLinearTrend::trendScore($filter);      // v̂ / √P_vv — t-статистика тренда
```

Установившийся режим при регулярных барах: `AlphaBetaFilter::forConstantVelocity(σ_a, σ_r, dt)`
— те же оценки при постоянном dt без ковариации, ≈ 0.06 мкс/шаг.

## Расширение — Зингер

Если тренды «выдыхаются», замените `ConstantVelocity` на `Generic\Singer(σ, τ)`:
`F₂₂ = e^{−dt/τ}`, τ — память тренда в секундах.

## Диагностика

- NIS по каналу цены (скользящее среднее 100) должен лежать в `[0.74, 1.30]`;
  устойчиво выше — `σ_a` или `R` занижены.
- Автокорреляция невязок на лаге 1 вне ±1.96/√N — пропущена динамика (нужен снос или Зингер).
