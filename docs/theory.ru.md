## 1. Модель пространства состояний

Дискретная линейная гауссовская система:

```
x_k = F_k · x_{k−1} + B_k · u_k + w_k,     w_k ~ N(0, Q_k)     уравнение состояния
z_k = H_k · x_k + v_k,                     v_k ~ N(0, R_k)     уравнение наблюдения
```

| Символ | Размер | Смысл | В биржевом контексте |
|---|---|---|---|
| `x_k` | n×1 | скрытое состояние | справедливые цены, тренды, hedge-ratio — то, чего *нет* в стакане |
| `z_k` | m×1 | наблюдение | котировки, сделки, цены на разных площадках |
| `F_k` | n×n | переход состояния | как цена дрейфует за Δt, как затухает премия |
| `B_k u_k` | n×1 | известное управление | известный дивиденд, купон, ребалансировка |
| `H_k` | m×n | проекция состояния в наблюдения | «пай = Σ wᵢ·pᵢ + премия» |
| `Q_k` | n×n | ковариация шума процесса | ковариация доходностей за Δt |
| `R_k` | m×m | ковариация шума измерения | спред, дискретность цены, латентность |
| `w_k`, `v_k` | — | белые, гауссовы, взаимно независимые | допущения, которые рынок нарушает (§16) |

Оптимальность держится на линейности, гауссовости, марковости, белизне и
независимости `w` и `v`. У каждого нарушения есть своё лечение (§13–§16).

**В библиотеке.** `Contract\MotionModel` отдаёт `F_k, Q_k, B_k u_k` как
функции от `dt`; `Contract\ObservationModel` — строки `H_k` (разреженные) и
диагональ `R_k`. Индекс `k` не формальность: ничего не кэшируется, пока
модель не объявит себя `StationaryModel`, и даже тогда — только по
квантованному `dt` (`FilterConfig::withMatrixCache`).

## 2. Что оптимизирует фильтр Калмана

Фильтр — это рекурсивный байесовский вывод для гауссовской модели:
апостериорное распределение `p(x_k | z_{1:k})` остаётся гауссовым, поэтому
среднее `x̂_k` и ковариация `P_k` описывают его полностью и обновляются
только они.

Два эквивалентных взгляда:

1. **Байесовский.** `predict` — маргинализация по `x_{k−1}` (свёртка
   гауссиан); `correct` — умножение априорной плотности на правдоподобие с
   нормировкой.
2. **MMSE.** `x̂_k` минимизирует `E[‖x_k − x̂_k‖²]` среди всех оценок,
   линейных по наблюдениям, — а при гауссовом шуме среди *всех* оценок вообще.

Второй взгляд важен для рынка: при тяжёлых хвостах фильтр не ломается, он
лишь перестаёт быть оптимальным и становится уязвим к выбросам. Поэтому
гейтинг (§8) — часть ядра, а не опция.

## 3. Уравнения фильтра

**Прогноз (time update)**

```
x̂⁻_k = F_k · x̂_{k−1} + B_k · u_k          (1)  априорное среднее
P⁻_k  = F_k · P_{k−1} · F_kᵀ + Q_k          (2)  априорная ковариация
```

(2) читается так: вчерашняя неопределённость, прокрученная через динамику,
плюс новая неопределённость от мира.

**Коррекция (measurement update)**

```
ỹ_k = z_k − H_k · x̂⁻_k                     (3)  невязка
S_k = H_k · P⁻_k · H_kᵀ + R_k               (4)  ковариация невязки
K_k = P⁻_k · H_kᵀ · S_k⁻¹                   (5)  усиление Калмана
x̂_k = x̂⁻_k + K_k · ỹ_k                     (6)  апостериорное среднее
P_k  = (I − K_k H_k) · P⁻_k                 (7)  апостериорная ковариация — НЕУСТОЙЧИВАЯ ФОРМА
```

`K` — это отношение «насколько я не уверен в состоянии» к «насколько я не
уверен в измерении». При `R → 0` оценка целиком верит измерению, при `R → ∞`
игнорирует его. Невязка `ỹ_k` — центральный диагностический объект: для
корректной модели это белый гауссов процесс с ковариацией `S_k` (на этом
построены §8–§11).

**В библиотеке.** Уравнения (5) и (7) существуют только в
`tests/Reference/NaiveKalmanFilter.php` — учебном эталоне, с которым
продакшен-формы сверяются с точностью 1e-9. Продакшен-код не обращает матриц
вообще: используется последовательная скалярная форма или решатель Холецкого
(§5).

## 4. Дискретизация и построение Q

Рыночные процессы естественны в непрерывном времени (броуновское движение,
Орнштейн–Уленбек), а тики приходят нерегулярно, поэтому `F(Δt)` и `Q(Δt)` —
функции интервала.

**Непрерывная модель:** `dx = A·x·dt + G·dβ` со спектральной плотностью `Q_c`.

**Точная дискретизация (Van Loan, 1978).** Строим блочную матрицу 2n×2n

```
M = [ −A      G·Q_c·Gᵀ ] · Δt          exp(M) = [ …    F⁻¹·Q ]
    [  0       Aᵀ      ]                          [ 0     Fᵀ   ]
```

тогда `F = (правый нижний блок)ᵀ`, `Q = F · (правый верхний блок)`. Матричная
экспонента — масштабирование-и-возведение-в-квадрат с аппроксимацией Паде(6).

**Замкнутые формы** (Van Loan не нужен):

*Случайное блуждание (RW) — цена без тренда*

```
F = [1],   Q = σ²·Δt
```

*Постоянная скорость / локальный линейный тренд (CV) — цена + скорость*

```
F = [1  Δt]        Q = σ_a² · [Δt³/3   Δt²/2]
    [0   1]                   [Δt²/2   Δt   ]
```

`σ_a` — интенсивность «рывков» скорости: это модель `p̈ = белый шум`. Не
путайте с диагональной `Q = diag(q_p, q_v)`, которая не соответствует ни
одному непрерывному процессу и даёт несогласованный фильтр.

*Постоянное ускорение (CA)*

```
F = [1  Δt  Δt²/2]      Q = σ_j² · [Δt⁵/20  Δt⁴/8  Δt³/6]
    [0   1   Δt  ]                  [Δt⁴/8   Δt³/3  Δt²/2]
    [0   0    1  ]                  [Δt³/6   Δt²/2  Δt   ]
```

*Орнштейн–Уленбек (OU) — среднереверсивная величина (спред пары, премия ETF, базис фьючерса)*

```
dx = −θ(x − μ)dt + σ dβ
F = e^{−θΔt},   u = μ(1 − e^{−θΔt}),   Q = σ²/(2θ) · (1 − e^{−2θΔt})
```

При `θΔt ≪ 1` вырождается в RW, при `θΔt ≫ 1` — в белый шум вокруг `μ`.

*Зингер — скорость с экспоненциально коррелированным шумом (тренд, который «выдыхается»)*

```
dv = −(1/τ)·v·dt + σ dβ
F = [1   τ(1−e^{−Δt/τ})]
    [0   e^{−Δt/τ}     ]
```

`Q` — через Van Loan или табличную формулу Зингера. Хорошо описывает
внутридневные импульсы.

**Многомерное обобщение.** Для вектора цен с ковариацией доходностей `Σ`
блок `Q_prices = Σ · Δt`; его внедиагональные элементы позволяют фильтру
вести неторгуемую бумагу через соседей.

**В библиотеке.** `Discretization\VanLoan` (общий случай) и
`Discretization\ClosedForm` (RW, CV, CA, OU, Зингер — у Зингера при
`Δt/τ < 0.05` включается степенной ряд без катастрофического сокращения).
Модели пересчитывают `F(Δt), Q(Δt)` при каждом новом `Δt`; ключ кэша — `Δt`,
квантованный до `dtQuantum` (по умолчанию микросекунда). В тестах замкнутые
формы совпадают с Van Loan с точностью 1e-10.

## 5. Численно устойчивые формы

Наивное уравнение (7) разваливается за тысячи шагов: `P` теряет симметрию,
затем положительную определённость, затем появляются отрицательные дисперсии
и NaN. На тиковых данных десять тысяч шагов — это минуты. Библиотека
реализует всю иерархию ниже за одним интерфейсом и позволяет выбирать форму
через `FilterForm`.

### 5.1 Форма Джозефа

```
P_k = (I − K_k H_k) · P⁻_k · (I − K_k H_k)ᵀ + K_k · R_k · K_kᵀ
```

Алгебраически тождественна (7) при точном `K`, но симметрична и
неотрицательно определена при *любом* `K`, даже неверном. Стоимость ~2n³
вместо n³.

### 5.2 Последовательная скалярная коррекция (по умолчанию)

При диагональной `R` (или приведённой к диагональной, см. ниже) каналы
обрабатываются по одному. Для канала `i` со строкой `hᵢ` и дисперсией `rᵢ`:

```
для i = 1..m:
    φ  = P · hᵢᵀ                    n×1, O(n·nnz(hᵢ))
    s  = hᵢ · φ + rᵢ                скаляр
    ỹ  = zᵢ − hᵢ · x̂               скаляр
    k  = φ / s                      n×1
    x̂  = x̂ + k · ỹ
    P  = P − φ · φᵀ / s             симметричный rank-1 downdate, O(n²)
```

Обращения матриц нет вообще. Симметрия точна, если считать верхний
треугольник и зеркалить. Пропущенный канал — пропущенная итерация. Результат
совпадает с блочной формой с точностью до округления — это теорема, а не
приближение.

**Отбеливание полной R.** `R = L·Lᵀ` (Холецкий), затем `z' = L⁻¹z`,
`H' = L⁻¹H`, `R' = I`. Делается один раз для стационарной `R`
(`Observation\DecorrelatedObservation`).

Слабое место: downdate может дать отрицательные собственные числа при
`r ≪ h·P·hᵀ` (сенсор намного точнее априорной оценки). Выше
`r ≈ 1e-6 · hPhᵀ` всё в порядке, ниже — берите UD или square-root.

### 5.3 Square-root фильтры

Хранят `S`, где `P = S·Sᵀ`. Число обусловленности `S` — корень из числа
обусловленности `P`, поэтому фильтр работает с удвоенной эффективной
точностью, а `P` не может стать неопределённой по построению.

*Поттер (скалярные измерения)*

```
φ = Sᵀ · hᵢᵀ
a = 1 / (φᵀφ + rᵢ)
γ = 1 / (1 + sqrt(a · rᵢ))
K = a · S · φ
x̂ = x̂ + K · ỹ
S = S − γ · K · φᵀ
```

Прогноз требует QR-разложения (Хаусхолдер) матрицы `[F·S | Q^{1/2}]ᵀ` — самый
дорогой predict и самый устойчивый фильтр.

### 5.4 UD-факторизация (Бирман–Торнтон)

`P = U · D · Uᵀ`, где `U` — верхняя унитреугольная, `D` — диагональная:
n(n+1)/2 чисел и ни одного квадратного корня. Скалярная коррекция Бирмана —
O(n²); прогноз Торнтона — модифицированная взвешенная ортогонализация
Грама–Шмидта (MWGS), O(n³) в плотном случае и O(n²) при разреженной `F`.
Устойчивость square-root при стоимости, близкой к последовательной форме:
рекомендуемая форма при `r ≪ hPhᵀ` и для `n ≤ 32`.

### 5.5 Сравнение

| Форма | correct (m каналов) | predict | Устойчивость | Когда использовать |
|---|---|---|---|---|
| Наивная (7) | n²m + nm² + m³ | 2n³ | ✗ расходится | только эталон в тестах |
| Джозефа | ~2n³ + nm² + m³ | 2n³ | ✓ симметрия, ПОО при любом K | полная R, малые m |
| Последовательная | 2mn² | 2n³ (O(n²) sparse) | ✓ точная симметрия; ПО почти всегда | **по умолчанию** |
| Поттер SRKF | ~3mn² | QR ~4n³ | ✓✓ ПО по построению | плохая обусловленность, r ≪ hPhᵀ |
| UD Бирман–Торнтон | ~2mn² | MWGS ~2n³ (O(n²) sparse) | ✓✓ ПО по построению, без sqrt | **точные сенсоры, n ≤ 32** |

Измеренное время шага — в таблице производительности README и в ADR-001.

**В библиотеке.** `enum FilterForm { Sequential, Joseph, UD, SquareRoot }`;
`Contract\CovarianceRepresentation` с двухфазным скалярным протоколом
`prepareScalar(h, r) → s`, `gain()`, `commitScalar(r)` (ADR-003), чтобы фильтр
мог отсечь или перевзвесить канал *между* вычислением `s` и фиксацией.
Реализации: `Covariance\DenseSequential`, `Joseph`, `UD`, `SquareRoot`,
сгенерированные ядра без циклов `Kernels\Sequential2/4` для n = 2, 4 и
опциональный `BlasDense` (OpenBLAS через FFI, ADR-006).

## 6. Информационный фильтр

Дуальная форма хранит `Y = P⁻¹` и `ŷ = P⁻¹x̂`. Коррекция превращается в
сложение:

```
Y_k = Y⁻_k + Hᵀ R⁻¹ H
ŷ_k = ŷ⁻_k + Hᵀ R⁻¹ z
```

— идеально при `m ≫ n` (сотни котировок на десяток состояний) и для
распределённого слияния (каждая площадка шлёт `HᵀR⁻¹H`, `HᵀR⁻¹z`, центр
складывает). Прогноз требует обращения. `Y₀ = 0` выражает «нет априорной
информации», чего ковариационная форма не умеет (`P₀ = ∞`).

**В библиотеке.** `Filter\InformationFilter` с `addInformation(h, r, z)` для
удалённых вкладов и конверсиями `fromCovariance()` / `covariance()` через
разложение Холецкого.

## 7. Пропуски, асинхронные и внеочередные измерения

**Пропуск канала.** Пропускаем итерацию. Фильтр делает прогноз, `P` растёт на
`Q`, остальные каналы корректируют; пропущенная компонента уточняется через
внедиагональные элементы `P`.

**Слепой шаг.** Только прогноз. Для RW-компонент дисперсия растёт линейно —
честное выражение незнания.

**Разная частота источников.** Каждое измерение несёт свой биржевой timestamp:

```
на измерение с t_i:
    Δt = t_i − t_last
    Δt > 0:  predict(Δt); t_last = t_i
    Δt = 0:  только correct (несколько измерений в один момент)
    Δt < 0:  внеочередное (ниже)
    correct(канал i)
```

**Внеочередные измерения (OOSM).** Тик с площадки B пришёл после тика с
площадки A, хотя произошёл раньше. Варианты:

1. *Отбросить* — обычный выбор в HFT (`OutOfSequencePolicy::Drop`).
2. *Ретродикция* (Bar-Shalom, 2002) — внести запоздавшее измерение через
   обратный одношаговый переход; точно на один шаг назад
   (`Filter\Retrodiction`, `OutOfSequencePolicy::Retrodict`).
3. *Окно переупорядочивания* — держать окно `W`, сортировать внутри него и
   выдавать с лагом `W` (`Infrastructure\Async\ReorderBuffer`,
   Pipeline-оператор).

**В библиотеке.** `Entity\Measurement` несёт `timestampNs` (int наносекунд от
эпохи, биржевое время), а не `dt`; `dt` фильтр вычисляет сам
(`KalmanFilter::step` / `stepRaw`). Про буфер и политики сессии — в
[async.ru.md](async.ru.md).

## 8. Гейтинг выбросов и робастность

Для корректной модели невязка распределена `N(0, S_k)`, поэтому нормированный
квадрат невязки `d² = ỹᵀ S⁻¹ ỹ` (расстояние Махаланобиса) — это `χ²(m)`, а на
канал — `χ²(1)`.

**Гейт χ².** Отвергнуть при `d² > χ²_{m,1−α}`:

| m | α = 0.01 | α = 0.001 | «3σ» |
|---|---|---|---|
| 1 | 6.63 | 10.83 | 9.00 |
| 2 | 9.21 | 13.82 | — |
| 4 | 13.28 | 18.47 | — |

Отвергнутое измерение не меняет ни `x̂`, ни `P`, но регистрируется. Несколько
отказов подряд (> 5) означают сломанную модель (сплит, изменение корзины), а
не плохие данные.

**Взвешивание по Хьюберу.** Вместо отбрасывания — понизить вес:

```
ψ(u) = u              |u| ≤ c
       c · sign(u)    иначе,      u = ỹ/√s,  c ≈ 1.345
```

что эквивалентно раздуванию `r` до `r_eff = r · (|u|/c)`. Мягче гейта, без
разрывов, ценой небольшого смещения при чистом гауссовом шуме.

**В библиотеке.** `GatingPolicy::none() | sigma(k) | chiSquare(α) | huber(c)`
через `FilterConfig::withGating`; `Entity\ChannelOutcome::weight` равен 1 для
принятых каналов, лежит в (0, 1) для взвешенных по Хьюберу и равен 0 для
отвергнутых; `Diagnostics\ChannelHealth` считает отказы подряд и поднимает
`ModelBreakSuspected` после `FilterConfig::modelBreakThreshold`. Квантили
даёт `Diagnostics\ChiSquare` без ext-stats.

## 9. Проверки консистентности

Фильтр *консистентен*, когда его собственная неопределённость `P`
соответствует реальной ошибке. Самоуверенный фильтр (малая `P`) отвергает
хорошие данные, инертный (большая `P`) реагирует медленно. Три теста
(Bar-Shalom):

**NIS** — нормированный квадрат невязки, единственный тест, доступный без
знания истины:

```
ε_k = ỹ_kᵀ S_k⁻¹ ỹ_k ~ χ²(m),    E[ε_k] = m
```

Среднее по окну из `N` шагов имеет распределение `ε̄ ~ χ²(N·m)/N`; двусторонний
95 %-интервал при `N = 100, m = 1` — `[0.74, 1.30]`. Устойчиво выше → Q или R
занижены, ниже → шумы переоценены.

**NEES** — нормированный квадрат ошибки оценки, на синтетике с известной
истиной:

```
η_k = (x_k − x̂_k)ᵀ P_k⁻¹ (x_k − x̂_k) ~ χ²(n),    E[η_k] = n
```

Единственный тест, который проверяет `P` напрямую; обязателен в CI.

**Белизна невязок.** Автокорреляция `ρ(τ)` должна оставаться в пределах
`±1.96/√N`; значимая автокорреляция означает пропущенную динамику или цветной
шум измерения.

**В библиотеке.** `Diagnostics\ConsistencyMonitor` (скользящий NIS по каналам
и суммарный, автокорреляция на лагах 1..L, границы χ²), `Diagnostics\Nees` для
тестов, `UpdateResult::nis()`. Набор тестов консистентности прогоняет каждую
модель каталога по её собственной симуляции 50 000 шагов и требует среднего
NEES в `[0.9n, 1.1n]`; регрессионные модели (пары, динамическая бета)
используют ансамблевый протокол, потому что одна траектория не эргодична.

## 10. Наблюдаемость, установившийся режим и alpha-beta фильтр

**Наблюдаемость.** Состояние наблюдаемо, когда
`O = [H; HF; HF²; …; HF^{n−1}]` имеет ранг `n`. Ненаблюдаемая компонента
(снос при единственном канале «цена») всё равно оценивается — медленно, через
динамику, — и её дисперсия может расти. `Diagnostics\ObservabilityCheck`
сообщает ранг при сборке модели.

**Установившийся режим.** При стационарных `F, Q, H, R` априорная ковариация
сходится к решению дискретного алгебраического уравнения Риккати (DARE)

```
P = F·P·Fᵀ − F·P·Hᵀ(H·P·Hᵀ + R)⁻¹·H·P·Fᵀ + Q
```

и `K` становится константой: шаг — это `x̂ += K(z − Hx̂)`, O(nm).
`Diagnostics\SteadyStateSolver::dare` итерирует predict/correct до сходимости;
`Filter\SteadyStateFilter` работает с постоянным усилением и без `P` (и
отказывается обрабатывать неполные измерения — `K` рассчитан на полный набор
каналов).

**Alpha-beta фильтр** — установившийся KF для CV-модели с одним каналом:

```
p̂ = p⁻ + α(z − p⁻)
v̂ = v⁻ + (β/Δt)(z − p⁻)
```

Для *дискретной* модели с белым шумом ускорения
(`Generic\DiscreteWhiteNoiseAcceleration`) замкнутая форма Калаты точна через
индекс манёвренности `λ = σ_a Δt² / σ_r`:

```
r = (4 + λ − sqrt(8λ + λ²)) / 4,   α = 1 − r²,   β = 2(2 − α) − 4·sqrt(1 − α)
```

Для непрерывной CV-модели (§4) усиления берутся из DARE
(`AlphaBetaFilter::forConstantVelocity`). При ~0.06 мкс на шаг это самый
быстрый трендовый фильтр из возможных — первичная фильтрация
высокочастотных потоков.

## 11. Откуда берутся Q и R

Неверные `Q`, `R` — самая частая причина плохой работы фильтра.

### 11.1 Прямо из данных

- `R` для котировки: `(half_spread)²` плюс дисперсия дискретности `tick²/12`.
- `Q` для цен: выборочная ковариация доходностей за `Δt` на истории,
  очищенная от микроструктурного шума (реализованная ковариация с оптимальной
  частотой семплирования или two-scale realized variance).
- `θ, σ` для OU-компонент: AR(1)-регрессия `Δx` на `x` с поправкой на
  дискретизацию.

Быстро, грубо, достаточно для старта.

### 11.2 Максимум правдоподобия по невязкам

Логарифм правдоподобия наблюдений раскладывается по невязкам:

```
ℓ(θ) = −½ Σ_k [ ỹ_kᵀ S_k⁻¹ ỹ_k + ln|S_k| + m·ln(2π) ]
```

Каждое `ℓ(θ)` — один прогон фильтра по истории; максимизация — Нелдер–Мид
(без градиентов, `n_θ ≤ 10`). Положительные параметры параметризуются через
логарифм, SPD-матрицы — через множитель Холецкого. Это ровно та величина,
которую фильтр накапливает в `logLikelihood()`; калибруйте с выключенным
гейтингом, потому что отвергнутые измерения выпадают из суммы.

Стоимость: один прогон = N шагов; оптимизатор делает 100–1000 прогонов. Точки
одной итерации симплекса независимы — первое место, где окупается
`amphp/parallel`.

### 11.3 EM-алгоритм (Shumway–Stoffer, 1982)

E-шаг: фильтр + RTS-сглаживатель (§12) дают `x̂_{k|N}, P_{k|N}, P_{k,k−1|N}`.
M-шаг, замкнутые формулы:

```
Q̂ = (1/N) Σ_k [ P_{k|N} − F P_{k,k−1|N}ᵀ − P_{k,k−1|N} Fᵀ + F P_{k−1|N} Fᵀ
              + (x̂_{k|N} − F x̂_{k−1|N})(x̂_{k|N} − F x̂_{k−1|N})ᵀ ]
R̂ = (1/N) Σ_k [ (z_k − H x̂_{k|N})(z_k − H x̂_{k|N})ᵀ + H P_{k|N} Hᵀ ]
```

Правдоподобие не убывает, оптимизатор не нужен, оцениваются полные матрицы;
вблизи оптимума сходимость медленная (20–50 итераций).

### 11.4 Адаптивные схемы онлайн

- *Innovation-based adaptive estimation* (Mehra, 1970): по окну из `N`
  невязок `Ĉ = (1/N) Σ ỹỹᵀ`, затем `R̂ = Ĉ − H P⁻ Hᵀ`, `Q̂ ≈ K Ĉ Kᵀ`; `R̂`
  приходится проецировать обратно на положительные значения.
- *Sage–Husa*: экспоненциальное забывание для `Q̂`, `R̂` с нижней границей.
- *Многомодельность* (§14): несколько гипотез `Q`, смешиваемых по
  апостериорной вероятности режима.

**В библиотеке.** `App\Calibration\InnovationLikelihood` (ядро
`@offloadable`), `Parametrization` (`log`, `linear`, `cholesky:n` по
точечным путям в конфиге), `NelderMead` (батчевый вычислитель — 4 точки на
итерацию), `MultiStartNelderMead` (K симплексов синхронно — 4K точек за
раунд, устойчивость к локальным оптимумам, загрузка пула воркеров),
`Calibrator`, `ExpectationMaximization`;
`Infrastructure\Task\LikelihoodTask` + `ParallelCalibrator` для fan-out по
воркерам; `Adaptive\InnovationAdaptive`, `Adaptive\SageHusa`,
`Adaptive\AdaptiveNoise`.

## 12. Сглаживание

Фильтр даёт `x̂_{k|k}`. Задним числом доступны все данные `1..N`, и оценка
`x̂_{k|N}` точнее. Обратный проход Рауха–Тунга–Штрибеля:

```
для k = N−1 .. 1:
    C_k     = P_{k|k} F_{k+1}ᵀ (P⁻_{k+1})⁻¹
    x̂_{k|N} = x̂_{k|k} + C_k (x̂_{k+1|N} − x̂⁻_{k+1})
    P_{k|N} = P_{k|k} + C_k (P_{k+1|N} − P⁻_{k+1}) C_kᵀ
```

Нужны `x̂_{k|k}, P_{k|k}, x̂⁻_{k+1}, P⁻_{k+1}` для всех `k` — память O(N·n²)
(512 МБ на миллион тиков при n = 8). Лечение: сглаживание с фиксированным
лагом в окне `L` шагов или сброс траектории на диск.

Зачем это трейдеру: «истинный» тренд на истории для разметки, E-шаг EM и
честная оценка того, насколько фильтр запаздывал.

**В библиотеке.** `Contract\StepRecorder` + `KalmanFilter::setRecorder()`
питают `Smoothing\FilterTrajectory` (блоки `SplFixedArray`, опциональное
кольцо); `Smoothing\RauchTungStriebel` (с лаг-один ковариациями для EM),
`Smoothing\FixedLagSmoother`; `Infrastructure\Output\TrajectoryFile` для
бинарного сброса на диск; `App\Backtest\Engine` + `Report`.

## 13. Нелинейные расширения: EKF и UKF

Когда линейности не хватает: состояние в лог-ценах при наблюдении в ценах
(`z = exp(x) + v`); волатильность из `z = log(r²)`; дисбаланс стакана; цены
опционов как функция скрытой волатильности.

**EKF.** Линеаризация якобианами в текущей оценке:

```
прогноз:  x̂⁻ = f(x̂),        F = ∂f/∂x |_{x̂}
коррекция: ỹ = z − h(x̂⁻),     H = ∂h/∂x |_{x̂⁻}
```

дальше — стандартные уравнения. Работает при слабой нелинейности; расходится,
когда точка линеаризации далека от истины.

**UKF.** Вместо якобианов через `f`, `h` прогоняются 2n+1 детерминированных
сигма-точек, по ним восстанавливаются моменты. Производных не нужно, точность
второго порядка (у EKF — первого). Параметры `α, β, κ` (обычно `1e-3, 2, 0`).
Сигма-точки строго положительных величин могут уйти в минус — параметризуйте
через логарифм.

**В библиотеке.** `Contract\NonlinearMotionModel` (`propagate`, `jacobian`,
`processNoise`), `Contract\NonlinearObservationModel` (`project`,
`projectChannel`, `jacobianRow`, `channelVariance`);
`Filter\ExtendedKalmanFilter` переиспользует любое
`CovarianceRepresentation`; `Filter\UnscentedKalmanFilter` обрабатывает каналы
последовательно, пересчитывая сигма-точки от `P` на каждый канал. На линейной
модели оба воспроизводят KF с точностью до округления (проверено тестом).
`Generic\LinearMotionAdapter` / `Observation\LinearObservationAdapter`
оборачивают линейные модели. Стоимость UKF относительно KF — 3–5× в
зависимости от `n` (README).

## 14. Многомодельный фильтр (IMM)

`M` фильтров с разными гипотезами (`Q_calm`, `Q_volatile`, …) и марковская
матрица переходов между режимами `Π`. На каждом шаге: смешать начальные
условия каждого фильтра из всех апостериорных с весами из `Π` и текущих
вероятностей режимов; прогнать каждый фильтр; обновить вероятности режимов по
правдоподобию невязок `Λ_j = N(ỹ_j; 0, S_j)`; выдать смесь. Быстрое
переключение при смене режима без раздувания `Q` в спокойное время, ценой `M`
фильтров (на рынке `M = 2..3`).

**В библиотеке.** `MultiModel\InteractingMultipleModel`;
`regimeProbabilities()` — самостоятельно ценный сигнал. На синтетических
данных «спокойно/волатильно» переключение обнаруживается за ≤ 5 шагов
(проверено тестом).

## 15. Коррелированные и цветные шумы

**Корреляция `w` и `v`** (`E[w_k v_kᵀ] = M ≠ 0`): одна и та же новость двигает
и цену, и спред. Модифицированное усиление
`K = (P⁻Hᵀ + M)(HP⁻Hᵀ + R + HM + MᵀHᵀ)⁻¹`.

**Цветной шум измерения** — bid-ask bounce отрицательно автокоррелирован на
лаге 1. Лечение: *расширение состояния*, добавляем `ν_k = ρ ν_{k−1} + белый`,
тогда `z = Hx + ν`; шум измерения становится частью состояния, а `R → 0`, что
требует UD- или square-root-формы.

**В библиотеке.** `Observation\CorrelatedObservation` +
`DecorrelatedObservation` для полной `R`; `Finance\BidAskBounce` — пример с
расширенным состоянием (по умолчанию UD).

## 16. Специфика рыночных данных

**Лог-цены против цен.** Шум цены мультипликативен, поэтому аддитивная модель
в ценах несогласована. Либо работать в `log(price)` (стационарная `Q`;
линейные связи вроде `ETF = Σ wᵢ pᵢ` становятся нелинейными → EKF,
`Finance\LogPriceEtfBasket`), либо остаться в ценах с гетероскедастичной
`Q_k = diag(p̂_k) Σ diag(p̂_k) Δt` (`Generic\HeteroscedasticMotionModel`).

**Дискретность цены.** Шаг цены `tick` добавляет к `R` равномерный шум с
дисперсией `tick²/12`.

**Внутридневная гетероскедастичность.** Волатильность U-образна по дню.
`Finance\IntradayProfile` умножает `Q(t)` на профиль времени суток; либо
оценивайте онлайн (§11.4).

**Скачки.** Новости, сплиты, экспирации не гауссовы. Гейт их отвергает; серия
отказов поднимает `ModelBreakSuspected`; корпоративные события применяются
явно (`Infrastructure\Command\Split`, `Dividend`, `Rebalance`).

**Латентность и timestamp'ы.** Биржевое время ≠ время получения. `dt` всегда
берётся из биржевого времени; `receivedNs − timestampNs` — самостоятельная
величина для мониторинга.

**Детерминизм движка.** JIT PHP 8.2/8.3 (и `opcache.jit=1205`, и `1255`)
неверно компилирует две распространённые формы float-ядер: переиспользуемый
временный результат `a * const * b` и накопление «на месте»
`C[i,j] += a·B[p,j]`. Ядра библиотеки избегают обеих,
`Diagnostics\JitSanity::verify()` проверяет используемые формы при первом
создании фильтра, а `engineBugs()` сообщает, что именно ломает движок;
`Infrastructure\Task\WorkerPools::likeParent()` запускает воркеры с флагами
родителя, поэтому результаты побитово совпадают между процессами. Соблюдайте
те же два правила в собственных моделях. См. ADR-007 и ADR-008.

## 17. Оценка скорости изменения

У почти любого индикатора из слоя метрик на практике есть производная — темп,
с которым набирается дисбаланс, вымывается плотность ликвидности, расширяется
спред. Способов получить это число три, и они далеко не равноценны.

Пусть наблюдаемый ряд `y_t = x_t + ε_t`, шум `ε` белый со стандартным
отклонением σ, шаг дискретизации T.

**Конечная разность.** У `(y_t − y_{t−1}) / T` ошибка равна `σ√2 / T`.
Восстанавливаемый сигнал имеет порядок `ẋ`, значит отношение сигнал/шум есть
`ẋT / (σ√2)` — пропорционально T. Уменьшение шага ради более локальной
производной делает оценку хуже, и неограниченно. Именно этот оцениватель
используют четырнадцать из пятидесяти индикаторов референсного каталога.

**МНК-наклон по окну** (`deriv()` в Prometheus). Подгонка прямой по N точкам с
шагом T даёт наклон с дисперсией

    Var(b̂) = 12σ² / (T²·N(N²−1))

то есть ошибка падает как `N^{-3/2}` — заметно лучше. Платой служит то, что
длина окна — свободный параметр без обоснованного значения, что подгонка
предполагает линейность тренда на всём окне, что все точки взвешены одинаково
независимо от возраста, и что вместе с числом не приходит никакой оценки его
неопределённости.

**Фильтр Калмана с моделью постоянной скорости.** Состояние `[p, v]ᵀ`, шум
процесса — белое ускорение интенсивности σ_a, наблюдение — сам ряд (F и Q — в
§2.4). Фильтр является оценивателем `v` с минимальной дисперсией в рамках этой
модели и отличается от регрессии тремя существенными вещами:

- взвешивание прошлых наблюдений следует из модели, а не из выбранного окна:
  старые данные обесцениваются с той скоростью, с какой скорость реально могла
  измениться;
- окна не существует вовсе, поэтому нечего настраивать под инструмент и нечего
  перенастраивать при смене интенсивности тиков;
- `P_vv` выходит из той же рекурсии, так что скорость приходит со стандартной
  ошибкой. `v̂/√P_vv` — t-статистика, и тренд можно *проверить*, а не оценивать
  на глаз относительно порога.

Установившееся поведение — это alpha-beta фильтр из §10, а компромисс
управляется единственным безразмерным индексом манёвренности

    λ = σ_a·√(T³/3) / σ_r

неопределённость положения, вносимая за шаг, делённая на шум измерения. Малая λ
сильно сглаживает и отстаёт; большая следует за реальным движением за несколько
наблюдений и тащит за собой больше шума.

`Metric\Filtered\Derivative` это реализует, калибруя σ_r по разбросу
последовательных разностей (для «уровень плюс белый шум» этот разброс равен
σ√2) и выводя σ_a из λ. Работает с любой метрикой — поэтому один класс
заменяет все `dX` каталога. `examples/filtered-derivative.php` меряет все три
оценивателя против известной истинной скорости.

**Оговорка.** T-статистика хороша ровно настолько, насколько верна стоящая за
ней модель. Постоянная скорость — неверная спецификация для чистого случайного
блуждания, и при сильно сглаженной настройке фильтр уверенно сообщит о
скорости, которой нет. Это не дефект арифметики, а то, как ведёт себя
неправильно специфицированная модель, и именно поэтому рядом существует
`Metric\Regime\FlatMarket` с мерой, в которой нечего настроить неверно.
